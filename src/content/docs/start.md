## 关于 ClanNA 档案馆

不论你选用什么邮件提供商，都能给世界上任何人发送电子邮件，不必知道或考虑他们在用哪个服务。但是，传统的社交媒体不是这样—— Twitter 上的用户没法和 Threads 用户互相通信。你也不能在 YouTube 上关注 Twitter 的用户。

那么，是不是有一种方法，可以让这些平台相互通信呢？

有的兄弟/姐妹/非二元性别，有的。

联邦宇宙 (Fediverse) 是一个支持任何 ActivityPub 实现的社交媒体。不同服务器上的人可以互相联系、通信、关注……

而 ClanNA 档案馆就是这样的一个实例。

请参阅 [Fediverse 简明介绍](https://jointhefediverse.net/?lang=zh-hans)，了解更多联邦宇宙的工作原理。

## 在开始之前

建议你读读[服务器规则](/rules/)，了解服务器上禁止的话题。

下面是个快速的摘要，专为急性子定制。最终的管理还是按照规则来，不过只要你做到以下几条，一般想发什么都没问题：

- 禁止政治
- 友善交流
- 不要发垃圾广告
- 禁止真人 nsfw 图片
- nsfw 和敏感技术打 CW 遮罩

## 注册账号

现在来注册账号吧！所有注册都是人工审批的，所以你的账号可能需要 24h 或更久才能审批完成。

1. 导航到[档案馆](https://clanna.dev/)，选择「注册」，然后浏览和上面一样的服务器规则摘要。
2. 填入你的邮箱，以及一个强密码。禁止临时邮箱。
3. 在注册理由 Reason 处，简单介绍一下你自己吧。如果你不知道写点什么，试试分享「爱好」「特长」之类的东西。甚至吐槽和座右铭也可以！
4. 等待审批通过。
